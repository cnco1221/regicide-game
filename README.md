# 레지사이드 (Regicide) — 온라인 협동 카드게임

2~4명이 온라인으로 함께 즐기는 [Regicide](https://www.badgersfrommars.com/regicide) 협동 카드게임 구현체입니다.
표준 트럼프 카드 54장 규칙(하트/다이아몬드/클럽/스페이드 문양 효과, 조합, 동물 동료, 어릿광대, 양보 등)을 그대로 따릅니다.

## 로컬 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속 후, 한 명이 "방 만들기"로 방을 생성하고
나머지 인원(최대 4명)이 방 코드로 "방 참가하기"를 하면 됩니다.

## Render에 배포하기

1. 이 저장소를 GitHub에 올립니다 (이미 되어 있다면 생략).
2. [Render 대시보드](https://dashboard.render.com)에서 **New +** → **Web Service** 선택.
3. GitHub 저장소(`regicide-game`)를 연결합니다.
4. Render가 저장소 루트의 `render.yaml`을 자동으로 인식합니다 (Build: `npm install`, Start: `npm start`).
   - 자동 인식이 안 되면 직접 입력: Build Command `npm install`, Start Command `npm start`.
5. Instance Type은 Free로 충분합니다. Deploy를 누르면 몇 분 내로 URL이 발급됩니다.
6. 발급된 URL을 친구들과 공유하면 최대 4명이 함께 플레이할 수 있습니다.

서버는 방(room) 상태를 메모리에 보관하므로, Render 무료 플랜처럼 재시작/슬립이 있는 환경에서는
서버가 슬립했다가 깨어나면 진행 중이던 방 정보가 초기화됩니다.

## 규칙 요약

- 2인: 손패 7장, 조커 0장 / 3인: 손패 6장, 조커 1장 / 4인: 손패 5장, 조커 2장
- 각 턴: ① 카드 내기 → ② 문양 효과 적용 → ③ 피해 입히기 → ④ 반격 피해 방어
- ♥하트: 버린 더미에서 카드를 여관 더미 밑으로 회수 / ♦다이아몬드: 카드 뽑기 /
  ♣클럽: 피해 2배 / ♠스페이드: 적 공격력 감소(해당 적을 물리칠 때까지 누적)
- 적은 자신과 같은 문양의 효과에 면역이며, 어릿광대를 내면 그 면역이 사라집니다.
- 정확히 체력만큼 피해를 입히면 해당 적 카드가 여관 더미 맨 위로 돌아갑니다.
- 마지막 킹을 물리치면 승리, 반격 피해를 감당할 카드가 없으면 패배합니다.
